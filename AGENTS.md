# Project guide

WordPress plugin for a lightweight contact launcher. Runtime deliverable is `biologiism-social/`.
Read [HANDOFF.md](HANDOFF.md) and [OKF](docs/okf/index.md). Keep production changes explicit; do not embed credentials or add dependencies without need. Validate PHP with `D:\xampp\php\php.exe -l biologiism-social/biologiism-social.php`.
